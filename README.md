In this project :

A modern and responsive **Add To Cart** web application built using **HTML, CSS, and JavaScript**.
This project demonstrates the core functionality of an e-commerce shopping cart,
allowing users to add products, manage quantities, and view the total price dynamically.

Features

- 🛍️ Browse available products
- ➕ Add products to the shopping cart
- ➖ Increase or decrease product quantity
- 🗑️ Remove items from the cart
- 💰 Automatic total price calculation
- 📱 Fully responsive design
- ⚡ Fast and interactive user experience

---

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---


---
Works
- Users can browse available products.
- Clicking **Add to Cart** adds the selected item.
- Quantity can be increased or decreased.
- The total amount updates automatically.
- Items can be removed from the cart at any time.
